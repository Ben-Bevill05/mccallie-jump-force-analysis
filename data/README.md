# Data

The force-plate data used in this analysis is **not public**. It contains individual athlete records from McCallie School Strength & Conditioning.

To run the analysis, place the data file here as `jump_data.xlsx`. The data is read from the sheet named `Sheet6`, with these columns:

| Column | Description |
|---|---|
| `Jump Height` | Countermovement jump height (inches) |
| `Avg. Relative Propulsive Force` | Average propulsive force as a % of bodyweight |
| `Countermovement Depth` | Depth of the countermovement |
